# 20 — Módulo Programações

## Objetivo

O módulo Programações é responsável pelo planejamento completo de cada evento ministerial.

Cada programação representa um momento em que o ministério ArteCelebração servirá.

Exemplos:

- Culto Domingo Manhã
- Culto Domingo Noite
- Somos Atos
- Radical
- GF
- CR
- Tenda
- SAL
- EDL

---

# Responsabilidades

Uma programação deverá concentrar todas as informações necessárias para o planejamento musical.

Ela será o centro das operações do sistema.

---

# Informações principais

- Nome
- Contexto
- Data
- Horário
- Local
- Tema
- Texto Base
- Referência Bíblica
- Status

# Relacionamentos

Uma programação possui:

- blocos
- equipe de servos
- observações
- histórico

Cada bloco poderá possuir:

- repertório
- facilitador
- diretor musical
- observações específicas

---

# Objetivo da interface

Permitir que líderes organizem todo o planejamento ministerial em um único lugar.

---

# Próximas telas

- Nova Programação

---

# Estrutura Interna

Uma Programação poderá ser organizada em blocos.

Exemplos de blocos:

- Recepção
- Louvor Inicial
- Avisos
- Mensagem
- Santa Ceia
- Louvor Final
- Encerramento

Cada bloco poderá possuir características próprias e, quando aplicável, um repertório específico.

Essa abordagem torna o sistema flexível para atender diferentes tipos de eventos ministeriais, como cultos dominicais, encontros de jovens, retiros, conferências e demais programações da igreja.
