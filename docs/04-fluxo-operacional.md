# Fluxo Operacional

## Objetivo

Este documento descreve o fluxo completo de trabalho do líder do ministério ArteCelebração durante o planejamento, execução e encerramento de uma programação.

---

# 1. Criação da Programação

O Administrador cria uma nova programação utilizando um modelo recorrente ou preenchendo manualmente as informações necessárias.

Dados mínimos:

* Título
* Contexto
* Data
* Horário
* Local

Após salvar, a programação passa a existir no sistema.

---

# 2. Planejamento da Mensagem

O Administrador registra as informações relacionadas à mensagem.

Campos previstos:

* Tema
* Pregador
* Referência Bíblica
* Direcionamento Musical

Essas informações servirão como base para a escolha do repertório.

---

# 3. Montagem do Repertório

O Administrador consulta o catálogo de músicas e monta o repertório da programação.

Durante essa etapa será possível:

* adicionar músicas;
* alterar a ordem das músicas;
* remover músicas;
* registrar observações específicas para cada música.

O repertório pertence exclusivamente à programação.

---

# 4. Montagem da Equipe de Servos

O Administrador define quais integrantes participarão da programação.

Para cada integrante poderão ser informados:

* especialidades utilizadas na programação;
* papel ministerial exercido (Facilitador, quando aplicável);
* indicação do Diretor Musical (opcional).

Um integrante poderá exercer mais de uma especialidade na mesma programação.

---

# 5. Envio das Confirmações

Após concluir o planejamento, o Administrador envia a solicitação de confirmação aos integrantes escalados.

Cada integrante poderá:

* confirmar participação;
* recusar participação;
* responder posteriormente.

---

# 6. Acompanhamento

O Administrador acompanha o andamento das respostas.

O sistema apresentará, de forma visual:

* confirmações recebidas;
* recusas;
* pendências.

Caso necessário, a Equipe de Servos poderá ser ajustada antes da programação.

---

# 7. Execução da Programação

No dia da programação, todas as informações estarão disponíveis para consulta:

* mensagem;
* repertório;
* Equipe de Servos;
* observações.

---

# 8. Encerramento

Após a realização da programação, ela será considerada concluída.

Nenhum dado será perdido.

Todo o histórico permanecerá disponível para futuras consultas.

---

# 9. Evoluções Futuras

O fluxo operacional deverá permitir futuras expansões, como:

* sugestões automáticas de repertório;
* planejamento de ensaios;
* integração com WhatsApp;
* notificações automáticas;
* aplicativo para integrantes;
* estatísticas ministeriais;
* relatórios gerenciais.
