# Requisitos Funcionais

## Objetivo

Este documento descreve todas as funcionalidades previstas para o ArteCelebração Hub.

Os requisitos representam o comportamento esperado do sistema e servirão como base para o desenvolvimento, testes e evolução da plataforma.

---

# RF-01 — Gestão de Integrantes

O sistema deverá permitir:

* Cadastrar integrantes.
* Editar integrantes.
* Inativar integrantes.
* Consultar integrantes.
* Registrar múltiplas especialidades musicais para um integrante.
* Registrar habilitações ministeriais.

---

# RF-02 — Gestão de Programações

O sistema deverá permitir:

* Criar uma programação.
* Editar uma programação.
* Alterar data e horário.
* Definir contexto da programação.
* Definir título da programação.
* Informar local.
* Registrar tema.
* Registrar pregador.
* Registrar referência bíblica.
* Registrar direcionamento musical.
* Registrar observações.

---

# RF-03 — Gestão do Catálogo de Músicas

O sistema deverá permitir:

* Cadastrar músicas.
* Editar músicas.
* Inativar músicas.
* Consultar músicas.
* Pesquisar músicas.
* Organizar músicas por categorias futuras.

---

# RF-04 — Gestão do Repertório

O sistema deverá permitir:

* Adicionar músicas ao repertório.
* Remover músicas.
* Alterar ordem das músicas.
* Registrar observações por música.
* Reutilizar músicas em diferentes programações.

---

# RF-05 — Gestão da Equipe de Servos

O sistema deverá permitir:

* Adicionar integrantes à programação.
* Definir especialidades utilizadas.
* Definir facilitadores.
* Definir Diretor Musical.
* Remover integrantes.
* Editar participações.

---

# RF-06 — Confirmação de Participação

O sistema deverá permitir:

* Solicitar confirmação.
* Registrar confirmação.
* Registrar recusa.
* Registrar pendências.
* Consultar situação da equipe.

---

# RF-07 — Consulta de Programações

O sistema deverá permitir:

* Visualizar programações futuras.
* Visualizar programações realizadas.
* Consultar repertórios.
* Consultar equipes.
* Consultar históricos.

---

# RF-08 — Controle de Acesso

O sistema deverá permitir diferentes níveis de acesso conforme o perfil do usuário.

---

# RF-09 — Histórico

O sistema deverá manter o histórico de:

* Programações.
* Repertórios.
* Equipes de Servos.
* Participações.
* Confirmações.

---

# RF-10 — Dashboard

O sistema deverá apresentar:

* Próximas programações.
* Situação das confirmações.
* Programações pendentes.
* Indicadores gerais do ministério.
